# Anganwadi Backend API 🛠️

This is the Node.js/Express backend for the Anganwadi Assistant App. It handles user authentication, data storage (MongoDB), and the parent verification logic.

## 🚀 Setup & Installation

### 1. Prerequisites
- [Node.js](https://nodejs.org/) installed.
- A [MongoDB Atlas](https://www.mongodb.com/atlas) account (or local MongoDB).

### 2. Install Dependencies
Open a terminal in this folder and run:
```bash
npm install
